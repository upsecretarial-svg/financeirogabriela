# PLANO DE IMPLEMENTAÇÃO: COMPARATIVO DE EVOLUÇÃO MENSAL

ESTE PLANO VISA ADICIONAR UMA FUNCIONALIDADE DE ANÁLISE COMPARATIVA ENTRE O MÊS ATUAL E O MÊS ANTERIOR NO DASHBOARD PRINCIPAL, EXIBINDO PERCENTUAIS DE CRESCIMENTO OU QUEDA NO FATURAMENTO E RECEBIMENTO.

## 1. DASHBOARD EXECUTIVO (`src/routes/_authenticated/index.tsx`)
- **LÓGICA DE DADOS**:
    - AMPLIAR A BUSCA DE DADOS NO `useQuery` PARA INCLUIR O MÊS ANTERIOR AO SELECIONADO.
    - CALCULAR A VARIAÇÃO PERCENTUAL ENTRE OS DOIS PERÍODOS PARA FATURADO E RECEBIDO.
    - FÓRMULA: `((ATUAL - ANTERIOR) / ANTERIOR) * 100`.
- **INTERFACE DE KPIS**:
    - ADICIONAR UM INDICADOR VISUAL (BADGE) NOS CARDS DE "FATURADO" E "RECEBIDO" MOSTRANDO A SETA (SUBIDA/DESCIDA) E A PORCENTAGEM.
    - USAR CORES SEMÂNTICAS: VERDE PARA MELHORA, VERMELHO PARA BAIXA.
- **FEEDBACK VISUAL**:
    - INCLUIR UM PEQUENO TEXTO EXPLICATIVO (EX: "VS. MÊS ANTERIOR") PARA CONTEXTUALIZAR A PORCENTAGEM.

## 2. PAINEL DE CONTAS (`src/routes/_authenticated/painel-contas.tsx`)
- **COMPARAÇÃO DE DESPESAS**:
    - IMPLEMENTAR LÓGICA SIMILAR PARA O TOTAL DE CONTAS A PAGAR.
    - EXIBIR SE HOUVE AUMENTO OU REDUÇÃO NAS DESPESAS EM RELAÇÃO AO PERÍODO ANTERIOR.

## DETALHES TÉCNICOS
- TRATAMENTO DE DIVISÃO POR ZERO (CASO O MÊS ANTERIOR NÃO TENHA DADOS).
- USO DE `framer-motion` PARA ANIMAÇÃO DE SURGIMENTO DOS INDICADORES DE VARIAÇÃO.
- A LÓGICA DE DATA SERÁ BASEADA NO ESTADO `selectedMonth` JÁ EXISTENTE.
