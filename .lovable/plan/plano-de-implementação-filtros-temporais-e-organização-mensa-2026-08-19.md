# PLANO DE IMPLEMENTAÇÃO: FILTROS TEMPORAIS E ORGANIZAÇÃO MENSAL

O OBJETIVO É GARANTIR QUE OS DADOS (DASHBOARD, RECEBIMENTOS E ATENDIMENTOS) SEJAM EXIBIDOS POR PADRÃO PARA O MÊS ATUAL E PERMITIR A FILTRAGEM DE OUTROS PERÍODOS, EVITANDO A MISTURA DE DADOS DE DIFERENTES MESES.

## AÇÕES REALIZADAS

### 1. DASHBOARD (`src/routes/_authenticated/index.tsx`)
- IMPLEMENTAR UM FILTRO DE MÊS/ANO NO TOPO DO DASHBOARD.
- ATUALIZAR A `queryKey` E A LÓGICA DO `useQuery` (`dashboard-stats`) PARA RESPEITAR O MÊS SELECIONADO.
- GARANTIR QUE OS KPIS REFLETAM APENAS O PERÍODO ESCOLHIDO.

### 2. RECEBIMENTOS (`src/routes/_authenticated/recebimentos.tsx`)
- ADICIONAR UM SELETOR DE MÊS/ANO RÁPIDO AO LADO DOS CAMPOS DE DATA JÁ EXISTENTES.
- DEFINIR O INTERVALO PADRÃO (`from`/`to`) PARA O PRIMEIRO E ÚLTIMO DIA DO MÊS CORRENTE AO CARREGAR A PÁGINA.

### 3. ATENDIMENTOS (`src/routes/_authenticated/atendimentos.tsx`)
- ADICIONAR FILTROS DE DATA (`DE` / `ATÉ`) NA LISTAGEM DE ATENDIMENTOS (ATUALMENTE MOSTRA OS ÚLTIMOS 200 SEM FILTRO DE DATA).
- DEFINIR O PADRÃO PARA O MÊS ATUAL.
- ATUALIZAR A BUSCA PARA CONSIDERAR O PERÍODO SELECIONADO.

### 4. COMPONENTES REUTILIZÁVEIS
- SE NECESSÁRIO, CRIAR UM COMPONENTE DE `MonthPicker` PARA PADRONIZAR A ESCOLHA DE MESES EM TODO O SISTEMA.

## DETALHES TÉCNICOS
- USO DE `new Date()` PARA DETERMINAR O MÊS ATUAL.
- MANIPULAÇÃO DE STRINGS ISO (`YYYY-MM-DD`) PARA QUERIES NO SUPABASE.
- INVALIDAÇÃO DE CACHE DO TANSTACK QUERY AO MUDAR O FILTRO.
